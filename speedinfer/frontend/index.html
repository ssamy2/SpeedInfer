inference.py
import os
from openai import OpenAI

# Select a model returned by client.models.list()
client = OpenAI(
    base_url="https://speedinfer.com/v1",
    api_key=os.environ["SPEEDINFER_API_KEY"],
)

stream = client.chat.completions.create(
    model=client.models.list().data[0].id,
    messages=[
        {"role": "user", "content": "Explain quantum teleportation in two sentences."}
    ],
    max_tokens=128,
    stream=True,
)

for chunk in stream:
    if chunk.choices:
        print(chunk.choices[0].delta.content or "", end="", flush=True)

ENTERPRISE TRUST & DATA PRIVACY

Built for enterprise security.
Zero compromises.

SpeedInfer is architected from the ground up to meet stringent security, privacy, and compliance requirements for high-growth startups and enterprise AI workloads.

🛡️

Deployment-aware retention

The SpeedInfer Gateway does not retain prompt or completion content by default. Retention behavior of connected workers and external providers varies by deployment and is disclosed per provider.

🔒

End-to-End Encryption

All data in transit is encrypted using modern TLS 1.3 with forward secrecy. Internal data, storage buckets, and API key salts are protected with AES-256 encryption at rest.

📜

GDPR & CCPA Compliant

Full compliance with international data privacy regulations. Developers and organizations retain 100% intellectual property ownership of inputs and generated completions.

🔑

Granular RBAC Scopes

Role-based API key access control. Provision scoped API keys with least-privilege permissions (e.g. read-only, inference-only, storage-only) to protect production systems.

PRIVACY & DATA HANDLING

How your data and requests are handled.

The SpeedInfer Gateway does not retain prompt or completion content by default. Retention behavior of connected workers and external providers varies by deployment and is disclosed per provider. Usage records contain request metadata needed for metering and operations. Read the full privacy policy.

When you submit a sales or support request, SpeedInfer stores your name, email, optional company, subject, and message so the team can handle your request and respond by email. Requests are visible only to authorized administrators.

Contact details are used to handle your request, not to enroll you in marketing. Requests remain in the system until removed by the operator. For access, corrections, or deletion, email Support@speedinfer.com.

Account and API key metadata are used strictly for authentication and aggregated token usage metering. Private networking and any service-level commitments require a separate written agreement.
