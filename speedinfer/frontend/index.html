05 — DEVELOPERS FIRST

Familiar API.
Fresh possibilities.

Keep the SDK you know. Connect your application to SpeedInfer and start streaming from your deployed model with FP8 TensorRT-LLM acceleration.

✓ OpenAI-compatible endpoints✓ Server-sent event streaming✓ Per-key access and usage tracking✓ FP8 GEMM kernel acceleration
Explore documentation ↗
inference.py
from openai import OpenAI

# Connect to SpeedInfer's NVIDIA TensorRT-LLM accelerated endpoint
client = OpenAI(
    base_url="https://api.speedinfer.com/v1",
    api_key="sk-speedinfer-live-key",
)

stream = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-R1",
    messages=[
        {"role": "user", "content": "Explain quantum teleportation in two sentences."}
    ],
    extra_body={
        "kv_cache_dtype": "fp8",
        "tensorrt_llm_runtime": True
    },
    stream=True,
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="", flush=True)

PRIVACY & ZDR DATA POLICY

How your data and requests are handled.

Enterprise Zero Data Retention (ZDR) Guarantee: All prompt and completion tokens submitted to SpeedInfer inference endpoints are processed strictly ephemerally in GPU memory (VRAM) and are never logged, stored on persistent disk, or used for model training.

When you submit a sales or support request, SpeedInfer stores your name, email, optional company, subject, and message so the team can handle your request and respond by email. Requests are visible only to authorized administrators.

Contact details are used to handle your request, not to enroll you in marketing. Requests remain in the system until removed by the operator. For access, corrections, or deletion, email Support@speedinfer.com.

Account and API key metadata are used strictly for authentication and aggregated token usage metering. Dedicated enterprise VPC deployment options with VPC Peering / PrivateLink and custom SLAs are available via enterprise sales.
