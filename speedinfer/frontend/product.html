SPEEDINFER PLATFORM · SOFTWARE ARCHITECTURE

Software-Defined Gateway.
Unified Model Control Plane.

SpeedInfer is the API gateway and control plane that connects developer applications to high-performance AI models. We provide unified authentication, per-token metering, model registry routing, and fine-tuning orchestration. Open-source models are served by connected model workers, while closed-source proprietary models are routed through external providers.

OpenAI SDK · Python Integration 
from openai import OpenAI

# SpeedInfer is a drop-in software layer
client = OpenAI(
    base_url="https://speedinfer.com/v1",
    api_key=os.environ["SPEEDINFER_API_KEY"]
)

response = client.chat.completions.create(
    model="deepseek-r1",
    messages=[{"role": "user", "content": "Explain prefix caching."}],
    stream=True
)

# Low-latency streaming response
for chunk in response:
    print(chunk.choices[0].delta.content or "", end="", flush=True)

⚙️ Unified API Gateway & Control Plane

SpeedInfer operates strictly as a software control plane. Rather than hosting monolithic compute, we build the authentication gates, token-bucket rate limiters, model routing registries, and authoritative token metering pipelines that connect client applications to model endpoints with zero vendor lock-in.

⚡ Connected NVIDIA Worker Integration

SpeedInfer integrates with connected workers running NVIDIA TensorRT-LLM, NVIDIA Triton, CUDA 12+, and PagedAttention for open-source foundation models, while securely routing proprietary closed-source models to external providers. Connected workers handle low-level continuous batching and KV-cache reuse, with measured latency and transparent per-token billing.
