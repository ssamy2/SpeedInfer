SpeedInfer Developer API Reference

SpeedInfer provides an ultra-low latency, OpenAI-compatible developer platform for high-throughput LLM inference, serverless fine-tuning (LoRA / QLoRA), object storage, dataset management, and scoped key governance.

Authentication: All API requests require a Bearer token in the Authorization header.
Authorization: Bearer sk-speedinfer-xxxxxxxxxxxxxxxxxxxx

Base URLs & Environments

Production API requests are routed over TLS 1.3 with HTTP/2 and HTTP/3 support.

EnvironmentBase URLDescription
Productionhttps://speedinfer.com/v1Primary global production gateway
Local Developmenthttp://localhost:8000/v1Self-hosted Docker / local instance

Granular Permission Scopes

When creating API keys via POST /v1/keys or Console, you can restrict permissions to minimal privileges:

ScopeGrants Access To
inference (or chat:completions)Chat completions and legacy text completions
models:readModel discovery, architectures, pricing, and weights manifest
files:write / files:readUpload, read, and delete dataset files for fine-tuning
storage:write / storage:readCreate storage buckets and upload object artifacts
fine_tuning:write / fine_tuning:readLaunch, monitor, and cancel model fine-tuning jobs
keys:write / keys:readIssue, list, and revoke sub-API keys
usage:readQuery consumption metrics and credit balance
adminUniversal administrative superuser bypass

Retrieve Current User & Balance

GET /v1/auth/me

Returns the authenticated user's profile, organization role, verified email status, and current USD credit balance.

Model Pricing & Context Limits

GET /v1/workspace/pricing

Returns current token pricing per 1M input/output tokens, context windows, and storage rates across all supported architectures.

Usage & Rate Limits

GET /v1/usage

Retrieves aggregated token metrics, hourly request counts, and remaining rate limit quotas.

List Available Models

GET /v1/models

Lists currently active and warm models available for instant inference, complete with context windows and token pricing.

Retrieve Model Details

GET /v1/models/{model_id}

Retrieves detailed metadata for a specific base model or fine-tuned checkpoint.

Download & Export Model Weights

GET /v1/models/{model_id}/weights

Export model weights manifest with SHA-256 checksums or stream direct safetensors weights artifacts.

Query ParamTypeDescription
downloadbooleanSet true to initiate binary file download stream.
formatstringTarget format (e.g. safetensors, gguf). Default: safetensors.

Create Chat Completion

POST /v1/chat/completions

Creates a model response for the given chat conversation. Fully OpenAI SDK drop-in compatible.

FieldTypeDescription
modelrequiredstringModel ID to query (e.g. Qwen/Qwen2.5-7B-Instruct).
messagesrequiredarrayList of conversation turns (role and content).
temperaturefloatSampling temperature between 0.0 and 2.0. Default 0.7.
max_tokensintegerMax tokens to generate. Max: 32,768.
streambooleanStream partial tokens via Server-Sent Events (SSE).

Chat Completion Streaming (SSE)

POST /v1/chat/completions (stream=true)

Streams chunked token deltas via standard Server-Sent Events (SSE) protocol (text/event-stream).

Legacy Text Completions

POST /v1/completions

OpenAI-compatible raw prompt text generation endpoint.

Upload a File

POST /v1/files

Upload a training dataset or object. Automatically validates JSONL schema when purpose is fine-tune.

Form FieldTypeDescription
filerequiredfile (binary)The multipart file to upload.
purposestringTarget purpose: fine-tune, storage. Default: fine-tune.

Create Storage Bucket

Creates an isolated storage bucket for holding model weights, datasets, RAG vector indexes, and checkpoint blobs.

GET /v1/buckets

Returns a list of all object storage buckets owned by the account.

DEL /v1/buckets/{bucket_id}

Deletes a bucket along with all objects stored within it.

List Objects in Bucket

GET /v1/buckets/{bucket_id}/objects

Create Fine-Tuning Job

POST /v1/fine_tuning/jobs

Launch a parameter-efficient fine-tuning (LoRA / QLoRA) run on a specified base model using an uploaded dataset.

FieldTypeDescription
modelrequiredstringBase model name (e.g. Qwen/Qwen2.5-7B-Instruct).

hyperparametersobjectConfig for n_epochs, batch_size, lora_rank, lora_alpha.

List Job Events & Logs

GET /v1/fine_tuning/jobs/{job_id}/events

Real-time log stream and milestones emitted during model optimization.

Create Scoped API Key

POST /v1/keys

Programmatically issue API keys with custom permission scopes and rate limits for different microservices or applications.

GET /v1/keys

Lists all API keys associated with the account along with their scopes and usage status.

GET /v1/keys/{key_id}

Returns configuration and granted scopes for a designated API key ID.

Immediately invalidates and deactivates an API key.

      Quickstart
      
From Zero to First Inference in 60 Seconds (التشغيل السريع)

      

        

          SpeedInfer provides 100% drop-in API compatibility with the official OpenAI SDKs in Python and Node.js. 
          You only need to change your base_url to https://speedinfer.com/v1.
        

        
Python Example

        
from openai import OpenAI

client = OpenAI(
    base_url="https://speedinfer.com/v1",
    api_key="sk-speedinfer-your-api-key-here"
)

response = client.chat.completions.create(
    model="Qwen/Qwen2.5-7B-Instruct",
    messages=[{"role": "user", "content": "Explain KV-cache optimization in 2 sentences."}]
)
print(response.choices[0].message.content)

      

    


    
    

      Model Training
      
Fine-Tuning Qwen 2.5 with LoRA and QLoRA on SpeedInfer (تدريب النماذج)

      

        

          SpeedInfer allows training and fine-tuning custom adapters without managing raw GPU infrastructure or Docker containers. Upload your JSONL dataset, configure LoRA parameters (e.g. r=16, alpha=32), track metrics in real time, and deploy your fine-tuned model directly to an inference endpoint.
        

        
1. Prepare your dataset (train.jsonl)

        
{"messages": [{"role": "system", "content": "You are a customer support agent."}, {"role": "user", "content": "Where is my order?"}, {"role": "assistant", "content": "Please provide your order ID."}]}
{"messages": [{"role": "system", "content": "You are a customer support agent."}, {"role": "user", "content": "Can I return a damaged item?"}, {"role": "assistant", "content": "Yes, within 30 days."}]}

        
2. Upload and Launch Training

        
# 1. Upload dataset
curl -X POST https://speedinfer.com/v1/files \
  -H "Authorization: Bearer $SPEEDINFER_KEY" \
  -F "file=@train.jsonl" \
  -F "purpose=fine-tune"

# 2. Launch Job with LoRA Hyperparameters
curl -X POST https://speedinfer.com/v1/fine_tuning/jobs \
  -H "Authorization: Bearer $SPEEDINFER_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen/Qwen2.5-7B-Instruct",
    "training_file": "file-xxxxxxxxxxxx",
    "method": "qlora",
    "suffix": "support-v1",
    "hyperparameters": { "n_epochs": 3, "batch_size": 4, "lora_rank": 16, "lora_alpha": 32 }
  }'

      

    


    
    

      Low Latency
      
Ultra-Low Latency Streaming with Server-Sent Events (SSE) (البث الفوري)

      

        

          To deliver instant real-time typing experiences, SpeedInfer gateway disables internal buffering and streams raw token chunks directly 
          via chunked HTTP/2 streaming. TTFT (Time To First Token) is minimized through continuous batching.
        

        
import { OpenAI } from "openai";

const client = new OpenAI({
  baseURL: "https://speedinfer.com/v1",
  apiKey: process.env.SPEEDINFER_API_KEY
});

const stream = await client.chat.completions.create({
  model: "Qwen/Qwen2.5-7B-Instruct",
  messages: [{ role: "user", content: "Tell me a story about high-speed GPUs." }],
  stream: true
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || "");
}

      

    


    
    

      Security & Keys
      
Zero-Trust Scoped API Keys for Microservices (صلاحيات المفاتيح)

      

        

          Never share master account credentials across environments. SpeedInfer allows creating scoped keys restricted to 
          specific tasks, such as inference-only for production frontend proxies or storage-only for ETL pipelines.
        

        
curl -X POST https://speedinfer.com/v1/keys \
  -H "Authorization: Bearer $SPEEDINFER_MASTER_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "production-inference-bot",
    "permissions": "chat:completions,models:read",
    "rpm_limit": 300,
    "tpm_limit": 200000
  }'

      

    


    
    

      Storage & Buckets
      
Scalable Object Storage for Checkpoints and RAG Datasets (التخزين السحابي)

      

        

          SpeedInfer Buckets provide high-speed S3-compatible storage co-located with GPU compute clusters. Eliminate data egress costs and latency when feeding datasets to fine-tuning and inference pipelines.
        

        
# Create bucket
curl -X POST https://speedinfer.com/v1/buckets \
  -H "Authorization: Bearer $SPEEDINFER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "rag-embeddings", "description": "Vector indices for search"}'

# Upload binary artifact
curl -X POST https://speedinfer.com/v1/buckets/bkt-xxxxxxxx/objects \
  -H "Authorization: Bearer $SPEEDINFER_API_KEY" \
  -F "file=@index.bin"
